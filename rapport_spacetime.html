Chapitre 02 · Chapter 02

La Physique d'Einstein

Einstein's Physics — The Theory Behind the Simulation

Relativité Spéciale vs Générale

⚡ Relativité Spéciale (1905)

  • Concerne les objets qui se déplacent très vite
  • Plus tu vas vite, plus le temps ralentit
  • Rien ne peut aller plus vite que la lumière
  • La masse et l'énergie sont équivalentes : E = mc²
  • Exemple : les horloges des satellites GPS avancent différemment

🌌 Relativité Générale (1915)

  • Concerne la gravité et les objets massifs
  • La masse courbe l'espace-temps
  • La gravité n'est pas une "force" mais une courbure
  • Prédit les trous noirs et ondes gravitationnelles
  • Exemple : notre simulation ! La grille qui se déforme
🧠 En termes simples · In simple terms

Spéciale : La vitesse déforme le temps.
Générale : La masse déforme l'espace ET le temps.

Special: Speed warps time.
General: Mass warps space AND time.

La Courbure de l'Espace-Temps

🇫🇷 Français

Imaginez l'espace-temps comme un grand drap élastique tendu dans l'espace. Quand vous posez une bille dessus, le drap se creuse. Plus la bille est lourde, plus le creux est profond. C'est exactement ce que fait une étoile ou un trou noir avec l'espace-temps réel — il le courbe, et les autres objets "tombent" dans cette courbure, ce qu'on appelle la gravité.

🇬🇧 English

Imagine spacetime as a large elastic sheet stretched in space. When you place a marble on it, the sheet bends. The heavier the marble, the deeper the dent. This is exactly what a star or black hole does to real spacetime — it curves it, and other objects "fall" into this curvature, which we call gravity.

La Métrique de Schwarzschild

La formule qui décrit la courbure autour d'un objet massif sphérique :

ds² = -(1 - rs/r)c²dt² + dr²/(1-rs/r) + r²dΩ²
rs = rayon de Schwarzschild · c = vitesse de la lumière · r = distance au centre
rs = 2GM/c²
G = constante gravitationnelle · M = masse de l'objet · c = vitesse de la lumière
💡 Ce que ça signifie · What it means

Le rayon de Schwarzschild est la distance à partir de laquelle même la lumière ne peut plus s'échapper — c'est l'horizon d'événements d'un trou noir. Pour le Soleil, ce rayon est d'environ 3 km (le Soleil mesure 696 000 km !).

The Schwarzschild radius is the distance from which even light cannot escape — it's the event horizon of a black hole. For the Sun, this radius is about 3 km (the Sun is 696,000 km!).

La Dilatation Temporelle Gravitationnelle

Δτ = Δt × √(1 - rs/r)
Δτ = temps ressenti près de la masse · Δt = temps loin de la masse
⏰ Explication · Explanation

Plus vous êtes proche d'un objet massif, plus le temps s'écoule lentement pour vous ! Un astronaute proche d'un trou noir vieillit moins vite qu'un astronaute loin dans l'espace. Ce n'est pas de la science-fiction — c'est un fait mesuré expérimentalement.

The closer you are to a massive object, the slower time flows for you! An astronaut near a black hole ages more slowly than one far away in space. This is not science fiction — it's an experimentally verified fact.

Les Trous Noirs

🇫🇷 Français

Un trou noir se forme quand une étoile très massive s'effondre sur elle-même. Sa masse devient si concentrée que la courbure de l'espace-temps devient infinie en un point : c'est la singularité. La frontière autour de laquelle même la lumière ne peut s'échapper s'appelle l'horizon d'événements.

🇬🇧 English

A black hole forms when a very massive star collapses in on itself. Its mass becomes so concentrated that the curvature of spacetime becomes infinite at one point: this is the singularity. The boundary around which even light cannot escape is called the event horizon.

Concepts OpenGL Expliqués

OpenGL Concepts Explained — For Beginners

Comment OpenGL Dessine ?

🇫🇷 Français

OpenGL ne peut dessiner que 3 formes de base : un point, une ligne, et un triangle. Tout le reste — cube, sphère, grille — est construit en combinant ces formes primitives.

🇬🇧 English

OpenGL can only draw 3 basic shapes: a point, a line, and a triangle. Everything else — cube, sphere, grid — is built by combining these primitive shapes.

Les Shaders

🎨 Qu'est-ce qu'un shader ?

Un shader est un mini-programme qui s'exécute directement sur la carte graphique (GPU). Il existe deux types principaux :

• Vertex Shader : "Où placer ce point dans l'espace 3D ?"
• Fragment Shader : "Quelle couleur donner à ce pixel ?"

A shader is a mini-program that runs directly on the graphics card (GPU). There are two main types:
• Vertex Shader: "Where to place this point in 3D space?"
• Fragment Shader: "What color to give this pixel?" 

// Vertex Shader — positionne chaque point
const char* vertexShader = R"(
    #version 330 core
    layout (location = 0) in vec3 position;
    uniform mat4 MVP;
    void main() {
        gl_Position = MVP * vec4(position, 1.0);
    }
)";

// Fragment Shader — colorie chaque pixel
const char* fragmentShader = R"(
    #version 330 core
    uniform vec3 couleur;
    out vec4 fragColor;
    void main() {
        fragColor = vec4(couleur, 1.0);
    }
)";

La Matrice MVP

📐 Model · View · Projection

Pour afficher un objet 3D sur un écran 2D, on applique 3 transformations :

• Model : position/rotation de l'objet dans le monde
• View : position et orientation de la caméra
• Projection : perspective (objets lointains = plus petits)

Résultat : MVP = Projection × View × Model

To display a 3D object on a 2D screen, 3 transformations are applied:
Model (object position), View (camera), Projection (perspective).

Le Ray Casting

🇫🇷 Français

Pour placer un objet précisément où on clique dans une scène 3D, on utilise le Ray Casting : on lance un "rayon" depuis la caméra à travers le pixel cliqué, et on calcule où ce rayon touche la grille (plan Y=0).

🇬🇧 English

To place an object precisely where you click in a 3D scene, we use Ray Casting: we cast a "ray" from the camera through the clicked pixel, and calculate where this ray hits the grid (plane Y=0).

Chapitre 05 · Chapter 05

La Physique Simulée

Simulated Physics — From Newton to Einstein

La Loi de Newton (base)

F = G × M₁ × M₂ / d²
F = force · G = constante gravitationnelle · M₁, M₂ = masses · d = distance
💡 Ce que ça veut dire

• Plus les masses sont grandes → plus l'attraction est forte
• Plus la distance est grande → plus l'attraction est faible (divisée par d²)
• Les deux objets s'attirent mutuellement avec la même force

• Larger masses → stronger attraction
• Greater distance → weaker attraction (divided by d²)
• Both objects attract each other with the same force

Correction Post-Newtonienne (Einstein)

a = -GM/r² × [1 + (rs/r)(4 + v²/c²)]
Correction du 1er ordre de la Relativité Générale (1PN)

L'Intégration Runge-Kutta 4

🇫🇷 Français

Pour simuler le mouvement avec précision, on utilise la méthode Runge-Kutta d'ordre 4 (RK4). C'est une méthode numérique qui calcule la position future d'un objet en faisant 4 estimations successives, ce qui donne des orbites stables et précises même avec de grands pas de temps.

🇬🇧 English

To simulate motion accurately, we use the 4th-order Runge-Kutta method (RK4). This is a numerical method that calculates the future position of an object by making 4 successive estimates, giving stable and accurate orbits even with large time steps.
